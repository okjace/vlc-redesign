**VLC Redesign** is an unofficial build of VLC media player with an interface based on
**["I Redesigned VLC After 25 Years"](https://www.youtube.com/watch?v=ERFeOgqk324) by [Juxtopposed](https://www.youtube.com/@juxtopposed)**.

VLC media player is made by [VideoLAN](https://www.videolan.org) and its contributors. This project is not affiliated with or endorsed by VideoLAN or Juxtopposed.

| --- | --- |

### Installing

- **macOS:** unzip and open **VLC Redesign.app**. The first time, right-click it and choose **Open** (the app isn't notarized). It offers to install itself into Applications, add itself to the Dock and Desktop, and clear macOS's "damaged" warning for good.
- **Windows:** run the Setup `.exe`. The installer is unsigned, so if SmartScreen warns you, choose **More info**, then **Run anyway**. It installs next to any official VLC.
- **Linux:** make the file executable (`chmod +x`, or *Properties → Allow executing*) and open it. A setup wizard installs it to `~/Applications` and adds it to your applications menu, desktop and terminal (`vlc-redesign`). It also works on desktops where AppImageLauncher crashes (niri, Sway, Hyprland), and you can choose **Run without installing**.
